# Аватары для полевых диалогов

Файлы для компонента `FieldDialogPanel` (`useFieldDialog` / `showPanel`).

Именование: `{npc}_{emotion}.png`, например:

- `lena_neutral.png`, `lena_happy.png`, …
- `tom_neutral.png`, `tom_proud.png`, …

Эмоции в коде: `neutral` | `happy` | `worried` | `surprised` | `proud` | `sheepish`.

Рекомендуемый кадр: бюст, **≈ 96×128 px** или больше с `object-fit: cover`, `object-position: top`.

Если файла нет, подставляется эмодзи (Лена / Том).
