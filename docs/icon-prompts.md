# Иконки предметов: спрайт-листы

74 иконки = 9 цепочек × 8 (7 ступеней + генератор цепочки) + 2 ресурса.
Один лист на цепочку. После получения листа: положить в `art/sheets/<id>.png` → `npm run icons`.

---

## Технические требования к листу

| Параметр | Значение |
|---|---|
| Размер | 1536 × 1024 или 2048 × 1024 (лист ресурсов — вдвое уже) |
| Раскладка | **Ровно 8 предметов, два ряда по 4** (ресурсы — 2 в один ряд) |
| Фон | Однородный светлый, без градиента, текстуры и виньетки |
| Порядок | Слева направо, сверху вниз: ступени 1→7, восьмой — генератор |
| Не должно быть | Лишних и дублирующих предметов, подписей, рамок, номеров |

Нарезчик не режет по жёсткой сетке: он сам находит иконки по картинке (ряды по горизонтальным
полосам, внутри ряда — по разрывам) и подбирает порог разрыва под ожидаемое число. Поэтому
неровные интервалы и разное число элементов в рядах ему не мешают. Вотермарка сверху отсекается
автоматически.

**Что действительно ломает нарезку:**

- **Лишний или дублирующий предмет.** Самая частая ошибка генерации: 9 элементов вместо 8,
  либо генератор нарисован дважды, либо затесался предмет из другой цепочки. Определяется
  глазами, лечится либо перегенерацией, либо строкой в `SKIP_SEGMENTS` в `scripts/slice-icons.ts`.
- **Соприкасающиеся иконки.** Если два предмета налезают друг на друга, скрипт пробует разрезать
  широкий сегмент по самой разреженной колонке — обычно срабатывает, но лучше просить зазор.
- **Тёмный или текстурный фон.** Фон определяется по углам и убирается по цветовому расстоянию;
  цветной фон оставит кайму.

Если счёт не сошёлся, скрипт не пишет мусор, а сообщает об этом и предлагает посмотреть отладочную
картинку.

---

## Единый стиль

Вставлять в начало каждого промпта:

> Набор из 8 иконок для казуальной мобильной игры, сетка 4×2 на чистом белом фоне.
> Стиль: мягкая рисованная живопись, тёплая палитра, скруглённые формы, лёгкая объёмность
> без жёсткого контура. Освещение сверху-слева, одинаковое для всех иконок.
> Каждый предмет крупный, по центру своей ячейки, читается силуэтом. Без текста, без рамок,
> без теней за пределами ячейки. Все восемь иконок одного масштаба и одной толщины формы.

**Главное правило читаемости.** Иконка живёт на клетке 40–58 px. Соседние ступени цепочки
обязаны отличаться **силуэтом и доминирующим цветом**, а не деталями. Если две ступени
различаются только количеством мелких элементов — на поле они сольются.

## Порядок работы

1. Сгенерировать лист по промпту → сохранить как `art/sheets/<id>.png`.
   Имя файла должно совпадать с id цепочки — по нему скрипт понимает, что резать.
2. `npm run icons -- --debug` — нарезка плюс `art/debug/<id>.png` с пронумерованными рамками.
3. Посмотреть отладочную картинку: рамок должно быть ровно 8, каждая вокруг одного предмета.
4. Проверить в игре. Листы можно добавлять по одному: пока иконки нет, предмет рисуется эмодзи.

Полезные команды:

```bash
npm run icons -- hall_tea --debug
```

## Приёмка листа

- [ ] Ровно 8 предметов, ни одного лишнего и ни одного дубля
- [ ] Порядок слева направо и сверху вниз совпадает с таблицей
- [ ] Предметы не соприкасаются
- [ ] Фон однородный и светлый
- [ ] Соседние ступени различаются силуэтом, а не только деталями
- [ ] Уменьшить лист до 25% и посмотреть: если две ступени сливаются — переделывать
