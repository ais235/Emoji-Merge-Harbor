# Диалоги и персонажи «Кафе Лены»

Единый справочник по текстам из кода на момент составления. Источники указаны рядом с каждым блоком.

---

## 1. Персонажи сюжета (NPC)

Отображаются в модальном диалоге на экране «Дом» (`DialogModal.tsx`). У каждого свой эмодзи, цвет подложки и имя в UI.

| ID в коде | Имя в игре | Эмодзи | Назначение |
|-----------|------------|--------|------------|
| `lena` | Лена | 👩‍🍳 | Героиня, владелица кафе бабушки |
| `tom` | Том | 👨‍🔧 | Сосед / помощник («гараж», терраса) |
| `guest` | Незнакомка | 🎭 | Загадочная постоянная гостья |

Тип в коде: `StoryBeat["npc"]` — файл `src/story/storyData.ts`.

## 2. Сюжетные биты (очередь диалогов)

Логика выбора следующего диалога: `StoryEngine` (`src/story/StoryEngine.ts`). Диалоги показываются только на экране **hub**, без миниигры поверх.

Условия (`condition`):

- `level` — уровень игрока ≥ значения  
- `zone_unlocked` — зона открыта в прогрессии  
- `upgrade_bought` — куплен апгрейд (для стула сюжетный id `chair` в данных мапится на `chair_fix` в сохранении)  
- `orders_completed` — всего выполнено заказов ≥ числа  

Биты с `chainOnly: true` в общую очередь **не попадают**, только как продолжение по выбору `nextBeatId`.

### Таблица всех битов `STORY_BEATS`

| ID | Условие | Персонаж | Текст реплики | Варианты ответа |
|----|---------|----------|---------------|-----------------|

| `start_b` | уровень ≥ 1 | Лена | Бабушка открыла это место 30 лет назад. Говорила — главное тепло, не деньги. | «Красивая история» / «Хватит, за работу!» *(chainOnly)* |
| `first_order` | заказов ≥ 1 | Лена | Первый гость! Он сказал, что приведёт друзей. Кажется, дело пошло! | «Отлично!» / «Главное не спешить» |
| `first_upgrade` | куплен апгрейд `chair` | Том | Слышал, ты обновляешь место! Если что — у меня в гараже полно старых вещей. | «Спасибо, Том!» / «Что именно есть?» → `tom_garage` |

Подсказка UI внизу карточки: «Нажми, чтобы продолжить».

## 3. Обучение на поле (онбординг)

Компонент `OnboardingOverlay.tsx`. Три шага поверх миниигры для игроков 1-го уровня, пока не отмечен бит `onboarding_done`.

| Шаг | Заголовок | Текст | Кнопка |
|-----|-----------|-------|--------|
| 1 / 3 | Слияние (↑) | Выдели предмет кликом, затем перетащи его на такой же — получится предмет следующего уровня! | Понятно |
| 2 / 3 | Заказы (↑) | Выполняй заказы — получай монеты и опыт для прокачки кафе! | Ясно |
| 3 / 3 | Корзина (↓) | Корзина 🧺: первый клик выделяет, второй клик по ней выдаёт предмет рядом (нужны энергия и пустая клетка). Энергия восстанавливается со временем! | Начать играть! |

## 4. Модальное окно «Как играть»

Вызывается из миниигры по запросу (`App.tsx`, туториал отдельно от онбординга).

Заголовок: **Как играть**

1. Нажми на **корзину 🧺** — рядом появится предмет 1 уровня, пока на клетке есть заряды.  
2. Объединяй **одинаковые** предметы, чтобы получить новый уровень!  
3. Выполняй **Заказы** сверху, чтобы получать монеты и опыт.

Кнопка: **Понятно**.

## 5. Короткие реплики при покупке апгрейдов

После покупки предмета ремонта или мета-улучшения показывается тост из `src/upgradeDialogs.ts`: одна строка на id апгрейда (зал, кухня, спальня, ванная, терраса, офис, лаунж, тайная комната, сад, мета-магазин).  

Если для id нет отдельной строки, используется **fallback по зоне** (например: зал — «Это место начинает оживать…», кухня — «Теперь можно готовить… почти как раньше.» и т.д.).

Полный перечень реплик — в файле **`src/upgradeDialogs.ts`** (объекты `LINES` и `ZONE_FALLBACK`).
